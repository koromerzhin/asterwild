# Asterwild

Asterwild is an independent 2D space exploration, adventure, building, survival and discovery game.
It is conceived as a spiritual successor to Starbound, with its own identity, mechanics, universe, assets and code.

## Status

Early development. Phase 0 (preparation) and Phase 1 (playable prototype) in progress.

## License

## Building

```sh
cargo build
cargo run
```

Requires Rust stable, and the usual Linux graphics/audio system libraries (ALSA, X11/Wayland, Vulkan).
