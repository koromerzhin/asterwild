# Roadmap — Asterwild

## Phase 0 — Preparation (current)
- Environment study: done.
- Bevy technical study: in progress.
- Starbound public study: planned.
- Git/GitHub init: in progress.
- Initial docs: in progress.
- Minimal architecture: in progress.

## Phase 1 — Playable prototype
- Window, camera, character, movement, jump, collisions.
- Block terrain, break/place blocks.
- Small generated zone.
- Basic resources, minimal inventory.
- Save/load.

## Phase 2 — First planet
- Procedural generation, biomes, relief, caves.
- Resources, vegetation, creatures, day/night, weather.

## Phase 3 — Gameplay
- Full inventory, crafting, equipment, weapons, combat, enemies, progression, technologies.

## Phase 4 — Space exploration
- Spaceship, star systems, multiple planets, navigation, discoveries.

## Phase 5 — Living universe
- Civilizations, NPCs, autonomous behaviors, relations, trade, colonies, diplomacy, dynamic events.

## Phase 6 — Content and polish
- Deep progression, quests, bosses, balance, UI, audio, robust saves, modding, distribution.

## Phase 7 — Multiplayer
- Only after solid solo foundations.
