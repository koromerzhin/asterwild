# Gameplay — Asterwild

## Core loop (Phase 1)

1. Spawn on a small generated area.
2. Move, jump, collide with terrain.
3. Break blocks, collect drops.
4. Place blocks from inventory.
5. Save and reload.

## Systems (planned)

- World grid of blocks, chunks, load/unload.
- Procedural generation deterministic from seed.
- Persistent modifications separate from base generation.
- Inventory, crafting, equipment.
- Combat, enemies, bosses.
- Spaceship travel between systems.
- Civilizations, NPCs, colonies, economy.
- Save versioning with migrations.

## Non-linear progression

Multiple viable play styles: exploration, building, trade, diplomacy, survival, combat.
